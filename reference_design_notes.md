# Reference Design Analysis (Resume Aryan.docx)

## Fonts
- **Name**: Arial, 23pt, Center
- **Contact Info**: Arial, 9pt, Bold, Italic, Center
- **Section Headers**: Arial, 14pt, ALL CAPS, Bold
- **Body Text**: Times New Roman / Arial, 10pt

## Layout
- **Structure**: Column-based header for profile/name.
- **Section Dividers**: Gray horizontal lines (`#878787`, 1pt) under headers.
- **Colors**:
    - Primary Text: Black (`#000000`)
    - Links: Blue (`#1154CC`)
    - Lines: Gray (`#878787`)

## Spacing
- Narrow margins (approx 0.5 inch).
- Tight line spacing (1.15x).
- Spacing before sections: ~10pt.
